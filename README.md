# Lost Ark API 기반 게임 경제 데이터 수집·가격 분석 프로젝트

Lost Ark API에서 생활재료·제작품·보석 가격을 수집해 SQLite에 저장하고, 제작원가·과거 가격변화·요일·주요 이벤트와 아이템 가격변화의 관계를 분석한 프로젝트입니다.

**자동 수집 → 가격일 정렬·데이터 검증 → 제작원가 구성 → 시계열 회귀 → 이벤트 전후 비교 → 추론 보완·민감도 분석**으로 이어지는 파이프라인을 구성했습니다.

아비도스 융화 재료에서는 제작원가와 가격변화의 관계를, 배틀아이템에서는 요일과 이벤트 전후의 상대 가격 움직임을 살펴봤습니다. 핵심 결과는 **아비도스의 원가와 가격변화 사이에 안정적인 양의 관계가 관측됐으며, 이벤트·요일 결과는 검정 방식과 모형 설정을 함께 고려해야 한다**는 것입니다.

## 문제 정의

| 분석 질문 | 분석 대상·접근 |
|---|---|
| 제작원가가 변한 날, 제작품 가격은 얼마나 함께 움직이는가? | 일반·상급 아비도스의 가격·원가 로그변화율과 과거 변화율을 이용한 동적 회귀 |
| 6/24 전후 가격 대비 원가 비율의 변화는 두 품목에서 다른가? | 일반·상급 아비도스 각각의 중단 시계열 분석과 품목 간 계수 차이 검정 |
| 배틀아이템 가격변화에 요일별 차이가 있는가? | 암흑 수류탄의 원가·전일 가격변화를 통제한 요일 검정 |
| 5/20 전후 성스러운 계열의 상대 프리미엄은 어떻게 달라졌는가? | 성스러운 폭탄·부적과 암흑 수류탄·정령의 회복약을 비교한 중단 시계열 분석 |

분석 범위는 **관측된 가격의 조건부 시계열 관계**입니다. 원가·수요의 인과적 기여나 미래 가격 예측 성능은 별도로 검증해야 합니다.

## 프로젝트 흐름

```text
Lost Ark API
  ↓
자동가격.py + GitHub Actions
  - 생활재료·제작품의 전일 평균가격, 보석의 수집시점 가격 수집
  ↓
lostark_ts_data.db
  - 생활재료 / 제작품 / 보석 테이블에 시계열 저장
  ↓
analysis/lostark_market_analysis.py
  - KST 가격일 정렬, 중복·0 이하 가격·누락일 검증
  - 제작경로별 원가, 가격·원가 변화율, 상대 프리미엄 구성
  - 동적 회귀·중단 시계열 분석, CSV·차트·감사 기록 생성
  ↓
analysis/lostark_market_robustness.py
  - 달력 간격을 반영한 표준오차와 품목 간 효과 차이 검정
  - 요일 다중비교 보정, 이벤트 이탈 진단, 모형 설정별 민감도 분석
```

기술 스택: **Python · requests · SQLite · pandas · NumPy · statsmodels · SciPy · Matplotlib · GitHub Actions**

수집과 분석은 별도 모듈로 실행합니다. 분석 모듈은 저장된 DB를 읽기 전용으로 열며, 기존 수집 workflow는 수집 작업을 계속 담당합니다.

## 데이터와 변수 설계

아래 결과의 기준 가격일은 **2026-03-29~2026-09-24**입니다. 달력상 180일이며, 핵심 분석 품목 6종은 각각 175일의 관측이 있습니다. 변화율·시차 변수·이벤트 제외 조건을 적용하면 회귀별 표본 수는 줄어듭니다.

핵심 품목은 일반·상급 아비도스 융화 재료, 암흑 수류탄, 성스러운 폭탄, 성스러운 부적, 정령의 회복약입니다. 보석은 시장 배경을 보여주는 참고 시계열로 사용합니다.

### 가격일과 데이터 품질

- 생활재료·제작품의 `YDayAvgPrice`는 전일 평균이므로 **KST 수집일에서 하루를 차감**해 가격일을 맞춥니다. 보석의 시점 가격은 수집일을 사용합니다.
- 같은 가격일·품목의 중복은 통합하되, 양수 가격이 서로 다르면 오류로 중단합니다. 기준 기간의 생활재료 53개·제작품 38개 중복 그룹에서 양수 값 불일치는 없었습니다.
- 0 이하 가격은 결측 처리합니다. 공통 누락 가격일인 4/11~4/14, 8/27은 보간하지 않습니다.
- 변화율과 시차는 실제 달력일 기준으로 계산해, 누락일을 건너뛴 두 관측을 연속된 하루로 취급하지 않습니다.

### 경제적 의미를 반영한 변수

| 변수 | 구성 | 분석 목적 |
|---|---|---|
| 아비도스 최저 제작원가 | 6개 생활 제작경로별 재료비·제작 골드비를 계산하고 관측 가능한 경로의 최솟값 사용 | 융화 재료 가격과 비교할 비용 기준 |
| 배틀아이템 제작원가 | 품목별 제작식의 재료비·제작 골드비를 생산 수량으로 나눔 | 배틀아이템 가격과 비교할 비용 기준 |
| 가격·원가 로그변화율 | `log(당일 값) − log(전일 값)` | 가격 수준이 다른 품목의 일간 변화 비교 |
| 가격 대비 원가 비율의 로그 | `log(가격 / 원가)`; 아비도스에는 최저 제작원가 적용 | 원가를 고려한 가격 프리미엄 변화 확인 |
| 성스러운 계열 상대 프리미엄 | 폭탄·부적의 평균 로그 프리미엄 − 암흑 수류탄·회복약의 평균 로그 프리미엄 | 비교 품목 대비 움직임 확인 |
| 과거 변화율·요일·시간 추세 | 달력 기준 시차와 요일·추세 변수 | 가격의 지속성과 반복되는 시간 패턴 반영 |

원가는 코드에 정의된 제작식과 생산 수량을 기준으로 계산합니다. 성스러운 계열의 기본 비교는 네 품목이 모두 관측된 날짜만 사용합니다.

## 분석 방법

### 1. 아비도스: 원가와 가격변화의 관계

가격 로그변화율을 당일 원가 로그변화율, 가격·원가의 1~3일 시차, 요일로 설명합니다. 6/24와 8/5 전후 ±7일 및 해당 구간에 시차가 걸리는 관측은 제외합니다. 기준 모형은 일반·상급 각각 127개 관측을 사용합니다.

당일 원가 계수는 다른 모형 변수를 통제했을 때의 동행 관계로 해석합니다. 같은 날 원가와 가격이 함께 결정될 수 있으므로 인과적인 원가 전가율을 직접 식별하지는 못합니다.

### 2. 이벤트: 수준 변화와 추세 변화

중단 시계열 분석(Interrupted Time Series, ITS)에 전일 종속변수, 시간 추세, 이벤트 이후 수준 변화(`Post`), 기울기 변화(`TimeAfter`), 요일을 포함합니다. 기본 이벤트 창은 전후 ±35일입니다.

- **6/24 아비도스:** `log(가격/원가)`를 분석하고, 일반·상급의 `Post` 차이를 직접 검정합니다.
- **5/20 성스러운 계열:** 상대 프리미엄을 분석합니다. 기울기의 변화와 이벤트 이후 기울기 자체를 각각 검정합니다.

### 3. 요일·이벤트 진단과 민감도

암흑 수류탄은 이벤트 당일을 제외한 표본에서 원가·전일 가격변화·요일의 관계를 추정합니다. 요일 전체의 공동검정과 월요일 대비 6개 요일 비교의 Holm 보정을 함께 사용합니다.

이벤트 날짜는 주변 구간을 적합에서 제외한 기준선과 실제 가격변화의 차이로 진단합니다. 이 기준선에는 이벤트 이후 데이터도 사용하므로 **사후 조건부 진단**으로 해석합니다.

누락일과 제외 구간을 고려해 표준오차는 실제 날짜 간격을 반영한 HAC(이분산·자기상관을 고려한 표준오차)로 보완했습니다. 시차 길이, 이벤트 창, HAC 폭, 비교 품목, AR 차수(과거 종속변수를 포함하는 시차 수)를 바꾸어 결과의 안정성도 확인했습니다.

## 핵심 결과

아래 수치는 기준 기간·기본 모형 사양의 **달력 HAC 7일, `n/(n-k)` 보정** 결과입니다. p값은 정규·카이제곱 근사를 사용하며, 요일별 비교에는 별도로 Holm 보정을 적용했습니다.

### 아비도스: 원가 관계와 품목 간 변화 차이

| 항목 | 추정값 | p값 | 해석 |
|---|---:|---:|---|
| 일반 아비도스 당일 원가 계수 | 0.6960 | 0.0007 | 원가가 1% 더 상승한 날 가격도 약 0.70% 더 상승하는 조건부 관계 |
| 상급 아비도스 당일 원가 계수 | 0.6985 | 0.0046 | 일반과 비슷한 크기의 양의 원가 관계 |
| 6/24 일반 아비도스 `Post` | 0.1122 | 0.0033 | 전일 값·추세·요일을 통제한 가격/원가 비율의 즉각 변화 약 +11.9% |
| 6/24 상급 아비도스 `Post` | -0.0011 | 0.9254 | 기준 모형에서 즉각 수준 변화의 증거가 제한적 |
| 6/24 일반−상급 `Post` 차이 | 0.1133 | 0.0184 | 두 품목의 수준 변화 차이를 직접 검정한 결과도 양수 |

원가와 전일 가격변화의 양의 관계는 품목별 27개 설정에서 유의성을 유지했습니다. 6/24의 품목 간 차이도 이벤트 창·HAC 폭·AR 차수 변경에서 양의 방향을 유지했습니다. 이 차이는 단기적인 조건부 변화이며 누적·영구 효과를 뜻하지 않습니다.

### 배틀아이템: 요일과 상대 프리미엄

| 항목 | 결과 | 해석 |
|---|---|---|
| 암흑 수류탄 요일 공동검정 | p=0.0371 | 요일 계수가 모두 0이라는 가설에 대한 반대 증거 |
| 목·토요일 개별 비교 | Holm 보정 p=0.1971 / 0.1744 | 두 요일 각각의 상승을 확정적인 규칙으로 보기 어려움 |
| 성스러운 계열 즉각 수준 변화 | `Post` 0.0456, p=0.1204 | 기준 모형에서 즉각 점프의 증거가 제한적 |
| 성스러운 계열 기울기 변화 | -0.0050, p=0.0067 | 이벤트 이전보다 조건부 기울기가 감소 |
| 성스러운 계열 이벤트 이후 기울기 | -0.0022, p=0.1106 | 기준 모형에서 이후 하락 추세 자체는 확정하기 어려움 |

성스러운 계열의 기울기 변화는 설정을 바꾸어도 음의 방향을 유지했지만, 즉각 점프와 이후 하락의 유의성은 이벤트 창·비교 품목·AR 차수에 따라 달라졌습니다.

암흑 수류탄의 이벤트 이탈 진단에서는 4/22·8/5·9/23에 각각 약 +6.4%·+9.4%·+10.9%의 상대 이탈이 관측됐습니다. 이는 이벤트 주변 ±7일을 제외해 적합한 기준선 대비 값이며, 이벤트의 인과효과나 검증된 예측 수익률로 해석할 수는 없습니다.

## 검증과 한계

실제 DB에서 기본 분석과 보완 분석을 기준 기간 및 검증 당시 전체 기간으로 실행했습니다. 전처리와 검정 계산을 확인하는 **테스트 19개가 통과**했으며, 기존 기준 CSV 6개의 회귀계수 74개도 부동소수점 오차 수준에서 재현했습니다. 상세 환경과 DB 해시는 [검증 기록](analysis/VALIDATION.md)에 남겼습니다.

해석에서 남는 한계는 다음과 같습니다.

- **수요·인과효과:** 거래량이나 독립적인 수요 자료가 없어 원가와 수요의 기여를 분리하기 어렵습니다. 동시 업데이트의 개별 효과도 식별하지 못합니다.
- **모형 적합성:** 일반 아비도스 ITS에는 잔차 자기상관이 남습니다. HAC 보완만으로 평균 관계의 모형 오류나 시차 종속변수의 내생성 문제가 해결되지는 않습니다.
- **원가의 범위:** 계산 원가는 정해진 제작식과 관측 가능한 경로를 사용합니다. 개인별 제작 조건과 실제 거래비용을 모두 반영한 실현 이익과는 차이가 있습니다.
- **분석 기간:** 약 6개월의 자료와 소수 이벤트에 기반한 결과입니다. 다른 기간에서도 같은 관계가 유지되는지는 추가 확인이 필요합니다.
- **예측 평가:** 이벤트 진단은 사후 분석입니다. 표본 밖 예측 성능과 거래 전략의 성과는 평가하지 않았습니다.

다음 개선에서는 거래량·업데이트 정보를 보강하고, 더 긴 기간에서 관계의 안정성을 확인하며, 잔차 구조를 개선하는 방향을 우선 검토할 수 있습니다.

## 실행 방법

Python 3.10 이상에서 저장소 루트를 기준으로 실행합니다.

### 저장된 DB로 분석 재현

API 키 없이 실행할 수 있으며, 분석 모듈은 DB를 수정하지 않습니다.

```sh
python -m pip install -r analysis/requirements.txt
python analysis/lostark_market_analysis.py --end-date 2026-09-24 --out analysis_outputs/reference
python analysis/lostark_market_robustness.py --end-date 2026-09-24 --out analysis_outputs/robustness
python -m unittest discover -s analysis/tests -v
```

`--end-date`를 생략하면 DB 전체 기간을 사용합니다. DB가 계속 갱신되므로 위 핵심 결과와 비교할 때는 가격일 상한과 [검증 기록의 DB 기준](analysis/VALIDATION.md)을 함께 확인해야 합니다.

기본 분석은 회귀계수 CSV, PNG 차트, 데이터 감사·모형 진단 JSON을 생성합니다. 보완 분석은 달력 HAC 결과, 품목 간 차이 검정, 요일 보정, 민감도·이벤트 진단 CSV 등을 생성합니다. **이 README의 추론과 p값은 보완 분석을 기준으로 하며**, 기본 재현 모듈의 차트·CSV에는 기존 관측행 기준 HAC 결과가 포함됩니다.

생성물은 기본적으로 Git 추적에서 제외됩니다. 파일별 설명과 상세 모형은 [분석 모듈 안내](analysis/README.md)를 참고하세요.

### API 가격 수집

수집을 실행하려면 Lost Ark API 키가 필요합니다. 아래 명령은 API를 호출하고 DB에 관측값을 추가합니다.

```powershell
python -m pip install requests
$env:LOSTARK_API_KEY="본인_API_KEY"
python 자동가격.py
```

GitHub Actions는 저장소 Secret의 `LOSTARK_API_KEY`를 사용합니다. 수집 workflow에는 매일 03:00 UTC(12:00 KST) 예약 실행과 수동 실행이 설정되어 있으며, 실제 시작 시각은 지연될 수 있습니다. 분석 패키지 설치와 분석 실행은 별도로 수행합니다.
